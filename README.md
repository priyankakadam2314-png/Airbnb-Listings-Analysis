# Airbnb Listings Analysis

## Project Overview

This project performs Exploratory Data Analysis (EDA) on an Airbnb Listings dataset to understand pricing patterns, customer ratings, reviews, and property characteristics across different countries.

The analysis focuses on identifying trends, relationships, and business insights using data visualization and statistical exploration.

---

## Objectives

- Explore and understand the Airbnb dataset
- Perform data cleaning and preprocessing
- Analyze listing distribution across countries
- Study Airbnb pricing patterns
- Analyze ratings and reviews distribution
- Identify relationships between numerical features
- Generate insights through visualizations

---

## Tools & Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

---

## Data Cleaning

The following preprocessing steps were performed:

- Removed unnecessary columns
- Removed text-heavy columns not required for analysis
- Converted rating and reviews columns to numeric format
- Handled missing values appropriately
- Renamed columns for consistency
- Removed duplicate records

---

## Exploratory Data Analysis

The following analyses were performed:

1. Top 10 Countries by Listings
2. Average Price by Country
3. Rating Distribution
4. Reviews Distribution
5. Rating vs Price
6. Average Price by Bedrooms
7. Reviews vs Rating
8. Correlation Heatmap

---

## Key Insights

- India has the highest number of Airbnb listings in the dataset.
- Most Airbnb listings have ratings above 4.5.
- Airbnb ratings are generally very high across properties.
- Property size significantly influences pricing.
- Bedrooms, beds, and guest capacity are strongly correlated.
- Reviews and ratings show relatively weak relationships with other numerical features.

---

## Conclusion

The analysis revealed important insights regarding Airbnb pricing, ratings, reviews, and property characteristics. Most listings maintain high customer satisfaction, while larger properties generally command higher prices. The study also highlights differences in listing distribution and pricing across countries.

---

## Recommendations

- Maintain high service quality to achieve better ratings.
- Optimize pricing based on property size and capacity.
- Encourage guest reviews to improve listing visibility.
- Explore additional factors such as amenities and seasonal demand for deeper analysis.
